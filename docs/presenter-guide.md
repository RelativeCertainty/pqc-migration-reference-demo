# Eight-to-ten-minute presenter guide

## 0:00-0:45 - Boundary

"This is an employer-neutral, static reference demo. Hosted records are
synthetic. There are no live providers, APIs, uploads, analytics, or stored
user data."

## 0:45-1:45 - Migration problem

Show why PQC is an enterprise inventory, dependency, risk, governance, and
evidence problem rather than a single algorithm replacement.

## 1:45-2:45 - Assessment method

Walk through authority, canonical inventory, source mobilization,
normalization, reconciliation, context, prioritization, waves, and limitations.

## 2:45-4:15 - Executable repository slice

Show the checked-in synthetic repository and scanner summary in Inventory.
Explain read-only input, symbolic-link refusal, conservative rules, relative
paths, no excerpts, create-only output, and deterministic reports.

## 4:15-5:15 - Evidence interpretation

Open the JSON or Markdown sample. State that matches are candidate
cryptographic use, not vulnerabilities or completeness proof.

## 5:15-6:30 - Architecture

Summarize domain center, application use cases, ports, anti-corruption
adapters, specifications, strategy policies, evidence envelopes, and
independent readback.

## 6:30-7:45 - Vertical slices

Use Discover, Normalize, Contextualize, Decide, Change, Verify, Measure.
Repository discovery is the first synthetic slice; TLS/PKI and SSH remain
planned authorized slices.

## 7:45-8:45 - Program system

Show stable epics/features, two-week story elaboration, YAML source of truth,
gates, evidence levels, and the 12-week roadmap.

## 8:45-9:30 - Close

"The public artifact proves a reproducible discovery and planning method. It
does not claim enterprise migration, certification, or live integration. The
next step in an authorized environment is a measured pilot cohort."

## Two-minute architecture summary

"The domain owns evidence, inventory, risk, migration decisions, and gates.
Use cases orchestrate those concepts through ports. Read-only discovery and
provider-specific systems live in adapters, protected by anti-corruption
translation. Specifications make detection and policy explainable. Strategies
make rollout and rollback replaceable. Each slice advances only as far as its
evidence: discovery, authorized decision, change, independent readback, then
measured outcome."
