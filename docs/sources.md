# Sources and authority

Project-authored methodology synthesizes, but does not reproduce or supersede,
the following external sources:

- NIST NCCoE, [Migration to Post-Quantum Cryptography](https://www.nccoe.nist.gov/applied-cryptography/migration-to-pqc): discovery, interoperability, performance, and migration practices.
- NIST CSRC, [Considerations for Achieving Crypto Agility](https://csrc.nist.gov/News/2025/considerations-for-achieving-crypto-agility): replaceability, policy, inventory, and lifecycle considerations.
- FS-ISAC, [Financial-services PQC migration roadmap](https://www.fsisac.com/newsroom/fs-isac-urges-global-coordination-for-migration-to-post-quantum-cryptography-in-financial-services): phased sector coordination and migration planning.
- NIST CSWP 39, *Considerations for Achieving Cryptographic Agility*: authoritative terminology should be checked against the current NIST publication register.
- CISA, NSA, and NIST, *Quantum-Readiness: Migration to Post-Quantum Cryptography*: inventory and roadmap guidance.

During an engagement, maintain a versioned standards register that
distinguishes final standards, drafts, implementation guidance, sector
guidance, and vendor claims. External citation is not endorsement.
