# Unified C# / React application

This directory is the sole application, incorporating the original reference
demo, durable assessment workflow and capacity-planning module.

Use the [root README](../../README.md) for the current setup and launch command,
and the [maintainer guide](../../docs/MAINTAINER_GUIDE.readable.html) for operation
and ports/adapters continuation. Start only the C# host; it serves React.

Other dated operator documents in this directory retain earlier workflow
explanations. Their previous candidate ports, release directories and historical
run counts are not current deployment claims. There is no separate maintained
reference-demo app, capacity app or Go host.

All data is synthetic. Enterprise authentication, SQL Server, approved HTTPS,
real source qualification and migration execution remain separate future gates.
