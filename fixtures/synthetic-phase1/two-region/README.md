```text
five synthetic source families
  -> ten linked source pages

  -> eight canonical assets
  -> eight evidence-linked dependencies
```

only to that fixture boundary and makes no enterprise-wide claim.

or deployment evidence. The dashboard is a rebuildable projection and is not
the system of record, an approval source, or an execution surface.
